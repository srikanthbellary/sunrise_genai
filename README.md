# Sunrise Gen AI

Official site for Sunrise Gen AI LLC — production systems for operations and messy knowledge.

## Stack

Static HTML, CSS, and inline SVG. IBM Plex Sans is self-hosted under the SIL Open Font License. A few lines of vanilla JavaScript drive the hero schematic motion.

## Local preview

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Deploy

GitHub Actions copies `index.html` and `fonts/` into `out/` and publishes that folder to GitHub Pages.
