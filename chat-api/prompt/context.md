# OpenStinger

Open-source portable MCP agent memory. Agents forget when a session closes; OpenStinger gives them one memory that travels — written once, recalled from any MCP client. Entities, decisions, threads, and artifacts land in a store the customer hosts. Context follows the work instead of the vendor. Self-hosted by design.

https://openstinger.com — https://github.com/srikanthbellary/openstinger

Inspectable memory: notes, tickets, diffs, and recall paths a person can open. Prefer a filesystem a reviewer can `cat` over an opaque vector blob.
